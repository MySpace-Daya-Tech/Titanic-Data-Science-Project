# 🚢 Titanic Data Science Project

> **A Machine Learning project built as part of my Data Science Internship to predict passenger survival on the Titanic dataset.**

## 📖 Project Overview

The Titanic Data Science Project focuses on analyzing passenger data from the famous Titanic disaster and building machine learning models to predict whether a passenger survived.

This project is being developed as part of my **5-week Data Science Internship**, where I am applying data analysis, visualization, feature engineering, and machine learning techniques to solve a real-world classification problem.

## 📊 Dataset

The project uses the famous **Titanic dataset**, containing passenger information such as:

- Passenger Class
- Age
- Gender
- Fare
- Embarked Port
- Family Information
- Survival Status

Target Variable:

**Survived**

- 0 = Did Not Survive
- 1 = Survived
